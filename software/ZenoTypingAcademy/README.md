# Zeno Typing Academy

Free premium typing-learning desktop project by Zeno Network.

## Latest calculator / numeric keypad module

This update adds a professional Calculator & Numeric Keypad Speed Trainer for accounting, invoice entry and data-entry practice.

### Included
- Ten-key touch typing with 4-5-6 home position
- Right-hand finger guidance
- 1-2-3, 4-5-6 and 7-8-9 drills
- 0 and decimal drills
- + - * / calculator operator practice
- Accounting amount entry
- Invoice/data-entry drills
- 1, 3, 5 and 10 minute real elapsed-time KPM tests
- Live KPM, CPS, accuracy, correct-key and error metrics
- Existing Hand & Finger Coach, speed tests, exam mode, Smart Tutor and premium typing games remain part of the project

Learning features remain free and offline-first.

## Windows source
Target: .NET 8 WPF (`net8.0-windows`).

A complete updated source ZIP is maintained with the project development package. The GitHub connector currently cannot create a new standalone repository from chat, so this project is stored under `ZNO_NETWORK/software/ZenoTypingAcademy/` as the GitHub project home until it is moved to its own repository.
